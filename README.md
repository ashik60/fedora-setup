# Fedora Setup

Personal Fedora Workstation Setup

## Usage

```bash
chmod +x install.sh
chmod +x gnome-settings.sh
chmod +x post-install.sh

./install.sh
```

After installation:

```bash
./post-install.sh
```

## Structure

- install.sh
- dnf-packages.txt
- flatpak-packages.txt
- gnome-settings.sh
- post-install.sh
- configs/
- fonts/
- wallpapers/
- scripts/
